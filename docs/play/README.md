# 上 Google Play 內部測試：光佑的操作步驟

目標：家人從 Google Play 安裝「竹科靈糧堂聖經」，之後由 Play 自動更新。
走「內部測試」：最多 100 位測試者，不需要審查等待，也不受新帳號「12 人測滿 14 天」的正式版門檻限制（那只管正式版）。

## 1. 開 Google Play 開發者帳號（只有你能做，驗證可能要幾天）

1. 到 https://play.google.com/console/signup ，選「個人」帳戶。
2. 付一次性的 US$25，填本名、地址、電話；準備身分證件和地址證明。證件上的姓名要和帳戶資料完全一致。
3. 驗證完成後，在一支 Android 手機（Android 10 以上、未 root）安裝「Play 管理中心」App，完成裝置驗證。

## 2. 建立應用程式

「建立應用程式」→ 名稱「竹科靈糧堂聖經」→ 預設語言「中文（繁體）」→ 應用程式 → 免費 → 勾選聲明。

## 3. 簽署金鑰（第一次上傳前決定）

建議沿用我們現在的簽署金鑰，不要讓 Google 另外產生一把新的。
這樣已經從 GitHub 安裝的人，之後可以直接由 Play 更新，不必先刪 App（刪 App 會失去只存在手機上的資料）。

做法：第一次建立版本時，畫面會問應用程式簽署金鑰（Play 管理中心的用字可能略有不同），選「匯出並上傳 Java KeyStore 中的金鑰」。畫面會提供 PEPK 工具和一段加密用公開金鑰；把那段公開金鑰給我，我在本機產生加密檔交給你上傳。上傳的是用 Google 公開金鑰加密過的檔案，只有 Google 解得開。

## 4. 內部測試

1. 「測試 → 內部測試 → 測試人員」：建立名單，貼上家人的 Gmail（最多 100 人）。
2. 「建立新版本」：上傳我提供的 `.aab` 檔，版本名稱填「0.5.11」，版本資訊填「新版閱讀頁：沉浸式閱讀、章尾繼續讀」。
3. 儲存 → 檢查 → 推出內部測試。
4. 在測試人員頁複製「加入測試」連結給家人。

## 5. 商店資訊與應用程式內容

- 商店資訊：照 [store-listing.md](store-listing.md) 填，截圖在 [screenshots/](screenshots/)。
- 應用程式內容：照 [app-content.md](app-content.md) 填。

## 6. 家人安裝

1. 用手機打開「加入測試」連結 → 接受測試 → 從 Play 安裝。
2. 打開 App → 用 Google 登入。第一次登入會自動建立成員帳號，不需要邀請碼。
