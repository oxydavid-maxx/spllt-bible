## 資料安全表單

整體：會收集資料；傳輸時加密：是；使用者可以要求刪除資料：是。

| 資料類型 | 收集 | 分享給第三方 | 用途 | 必要或選用 |
|---|---|---|---|---|
| 個人資訊 → 姓名（成員名稱，取自 Google 帳號名稱；團契報名表單的姓名，只保留對得上成員的人） | 是 | 否 | App 功能、帳戶管理 | 必要 |
| 個人資訊 → 使用者 ID（Google 帳號識別碼、成員編號） | 是 | 否 | App 功能、帳戶管理 | 必要 |
| 應用程式活動 → 其他使用者產生的內容（獎品提名文字；靈修日記只存在手機、不傳送，不算收集） | 是 | 否（提名文字交給 AI 服務估價，屬於代為處理的服務供應商，不算分享） | App 功能 | 選用 |
| 應用程式活動 → 其他動作（讀經完成、積分、投票、好友） | 是 | 否 | App 功能 | 必要 |
| 裝置或其他 ID (推播用裝置代碼；0.5.35 起 EAS Update 的隨機安裝識別碼；2026-10-21 起 App 自己的隨機安裝識別碼，送到本 App 伺服器記錄版本) | 是 | 否 (EAS 的安裝識別碼交給 Expo EAS Update 取得更新，屬於代為處理的服務供應商，不算分享；App 自己的只送到本 App 伺服器) | App 功能 (讀經提醒、取得 JavaScript/圖片更新)、分析 (管理者看每支手機的版本，協助更新) | 必要 (安裝識別碼每次檢查更新、每次連本 App 伺服器都會送出，不能關閉；推播代碼本身仍可不開) |
| 應用程式資訊和效能 → 當機記錄 (0.5.35 起：上一次啟動失敗時，下一次檢查更新附上最多 1024 字元的錯誤訊息和失敗的更新編號，供 expo-updates 故障復原) | 是 | 否 (Expo EAS Update, 服務供應商) | App 功能 | 必要 |
| 應用程式資訊和效能 → 其他應用程式效能資料 (2026-10-21 起：平台、App 版本、build 編號、正在使用的更新編號；每支手機只留最新一筆，只有管理者看得到：App 的「全體 (管理)」和管理者試算表的讀經統計頁) | 是 | 否 | App 功能、分析 | 必要 |
| 應用程式活動 → 應用程式互動 (2026-10-21 起：最後打開 App 的日期，只記到哪一天，跟上一列放在同一筆) | 是 | 否 | App 功能、分析 | 必要 |

管理者試算表的讀經統計頁 (2026-10-21 起多了平台、版本、最後打開的日期) 是教會自己的工作表，放在管理者的 Google 雲端硬碟，Google 是代為處理的服務供應商，不算分享；上面的資料都已列在上表。讀經統計頁的「管理者」勾選是同工設定的，不是從使用者手機收集，不另列。

不收集：位置、通訊錄、相片與影片 (相機畫面只在手機上辨識 QR 碼，不傳送)、財務資訊、健康資訊、網頁瀏覽紀錄、廣告 ID, 診斷 (效能、耗電、載入時間都不量)。
