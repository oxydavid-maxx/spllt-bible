Play 管理中心左側「政策與計畫 → 應用程式內容」逐項照填。答案依 2026-09-25 的程式碼整理；功能改了要回來更新。

| 項目 | 答案 |
|---|---|
| 隱私權政策 | https://github.com/oxydavid-maxx/spllt-bible/blob/main/docs/play/privacy-policy.md |
| 廣告 | 否，不含廣告 |
| 應用程式存取權 | 部分功能受限：主要功能需要 Google 登入；第一次登入會自動建立成員帳號，不需要邀請碼。審查人員用任何 Google 帳號登入即可 |
| 內容分級問卷 | 類別選「參考資料、新聞或教育」；暴力、性、粗話、藥物、賭博都選「否」；使用者之間可以互動：是（好友、小組內可見的獎品提名與投票）；分享使用者位置：否；數位商品購買：否 |
| 目標年齡層 | 9–12、13–15、16–17、18 以上（使用者 12 歲以上；12 歲落在 Play 的 9–12 級距，所以適用「家庭」政策）。符合方式：沒有廣告；不傳送廣告 ID、IMEI、MAC 等識別碼；加好友要雙方當面掃 QR 碼，好友之間只看得到名稱、讀經進度與活動是否報名，沒有聊天或私訊，不交換聯絡資料 |
| 新聞應用程式 | 否 |
| 政府應用程式 | 否 |
| 金融功能 | 否 |
| 健康應用程式 | 否 |
| 帳戶刪除 | 可以建立帳戶：是；刪除網址：https://github.com/oxydavid-maxx/spllt-bible/blob/main/docs/play/privacy-policy.md#%E5%88%AA%E9%99%A4%E5%B8%B3%E8%99%9F%E8%88%87%E8%B3%87%E6%96%99 ；App 內入口：帳戶頁「申請刪除帳號與資料」 |

## 資料安全表單

整體：會收集資料；傳輸時加密：是；使用者可以要求刪除資料：是。

| 資料類型 | 收集 | 分享給第三方 | 用途 | 必要或選用 |
|---|---|---|---|---|
| 個人資訊 → 姓名（成員名稱，取自 Google 帳號名稱；團契報名表單的姓名，只保留對得上成員的人） | 是 | 否 | App 功能、帳戶管理 | 必要 |
| 個人資訊 → 使用者 ID（Google 帳號識別碼、成員編號） | 是 | 否 | App 功能、帳戶管理 | 必要 |
| 應用程式活動 → 其他使用者產生的內容（靈修日記、獎品提名文字） | 是 | 否（提名文字交給 AI 服務估價，屬於代為處理的服務供應商，不算分享） | App 功能 | 選用 |
| 應用程式活動 → 其他動作（讀經完成、積分、投票、好友） | 是 | 否 | App 功能 | 必要 |
| 裝置或其他 ID（推播用裝置代碼） | 是 | 否 | App 功能（讀經提醒） | 選用 |

不收集：位置、通訊錄、相片與影片（相機畫面只在手機上辨識 QR 碼，不傳送）、財務資訊、健康資訊、網頁瀏覽紀錄、廣告 ID。
