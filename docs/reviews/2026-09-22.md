## 尚未完成與發布界線

- **Native 驗收尚未完成。** Pixel 已核實本人的讀經/高亮/積分/公告/帳戶、系統掃碼預覽與取消；只有一位正式成員，好友 claim、多人投票及管理寫入需用隔離 peer 驗。舊控制矩陣中未執行的條目不宣稱 PASS。
- F13：候選的 [更新 manifest](../../announcements/app-version.json) 尚未切換至這次已驗證 APK 的具體資產。完成驗收後才發布 release、更新連結並回讀；不宣稱原 `/releases/latest` 導向問題已結案。
- 各 focused 收據有重疊，**不加總測試數**；API、Node、Git fixture 或 debug 建置不能代替 Android 全流程驗收。
- 完成帳號/設定還原；帳務透過正常反向操作還原淨額並保留 audit。之後才合併/發布，安排家庭小範圍試用，再擴大使用。

## UIUX 建議

- 保留四 tabs 與既有讀經/音訊語意，以字級、間距與清楚層級改善閱讀，不加入新的學生設定流程。
- 已授權相機直接開啟；首次授權返回後維持原操作脈絡，使用者關閉後不被晚回覆拉走。
- 三票規則、pending/具體錯誤及 cache 舊資料標示放在操作附近，沿用原本的重試入口。
- 維持 sheet 關閉入口、完整捲動與大字/鍵盤可達性。讀經器已採用單排上方導覽和底部播放列，後續呈現調整先檢查真機的字級/長文與可達性。
