# 開放給主堂：青少／主堂、讀完接著靈修、獎品試算表 實作計畫

> **Execution:** The current native owner implements the complete release candidate, owns every FOCUS loop, and produces the exact candidate for RC. The plan does not mandate delegation or a separate reviewer. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓主堂 (成人) 也能用這個 App：每個人屬於「青少」或「主堂」，公告和獎品分開；讀完當天最後一章時直接接到靈修；獎品和兌換改由一份 Google 試算表管理；拿掉提名投票。

**Architecture:** 成員多一個歸屬 (`youth` | `main`)，後端依歸屬決定人數、獎品清單和公告內容。獎品與兌換的唯一來源是試算表，由 Apps Script 在編輯時推到後端；可兌換分數＝讀經得分 − 試算表兌換列加總。主堂公告是 LINE 公布欄貼出的週刊原圖，由 LINE webhook 下載保存。

**Tech Stack:** Expo SDK 56 / React Native 0.85、Node + SQLite 後端、LINE Messaging API、Google Apps Script。

## Global Constraints

- 名稱一律寫「青少」和「主堂」(維護者 2026-10-17)。
- App 只做 App 才做得到的事；別人做好的 (投票、表單、試算表) 用別人的，不包進 App (維護者 2026-10-17)。
- 給長輩用 (約 60 歲)：不要過度自動化，兌換用紙本，管理者記到試算表 (維護者 2026-10-17)。
- 這個 repo 是公開的：試算表、表單、排班表的網址和成員名字只放私人部署設定，不進程式碼或文件。
- 後端向下相容：舊版 App 連新後端不能壞。
- 平台差異只能放 `Platform.OS` 分支或 config plugin，並寫原因；兩個平台一起改。

## 定案規格 (維護者 2026-10-17)

### 一、讀經頁：讀完接著靈修

| 項目 | 規格 |
|---|---|
| 什麼時候出現 | 滑到當天最後一章的底，而且當天的靈修已上傳、還沒完成 |
| 不出現 | 今天靈修已完成；正在朗讀且開了自動接續 (念完會自己切過去)；選了某一節時先讓開 |
| 樣子、位置 | 跟「繼續讀 下一段 ›」同一個樣子、同一個位置，文字「接著讀靈修 ›」 |
| 按下去 | 切到靈修頁最上面；不自動朗讀、不幫你按完成 |
| 期限 | 每天都出現，沒有期限 |
| 收掉 | 葉子按鈕展開的「接續靈修 ›」7 天邀請；自動接續開關留在 ⋯ 選單 |

### 二、青少／主堂

| 項目 | 規格 |
|---|---|
| 歸屬 | 第一次登入選「青少」或「主堂」；現有成員都算青少，不再詢問；之後在帳戶頁可以改，改前先確認 |
| 公告 | 「青少｜主堂」兩個分頁，預設打開自己的；兩邊都看得到對方的分頁 |
| 青少分頁 | 照舊 (中亮排班表產生) |
| 主堂分頁 | 只放 LINE 公布欄的週刊原圖：最新一週在上、可以放大、保留最近 8 週 |
| 週刊怎麼認 | 同一次貼出的一組 A4 直式圖片；上線前用公布欄的歷史圖片回測，正確率回報維護者 |
| 人數 | 青少人數只算青少；主堂人數算全教會 (青少也算進去) |
| 獎品 | 青少、主堂各一份清單，各看各的 |
| 換獎品 | 一人一個積分帳戶，只在自己那邊換；紙本兌換，由管理者記到試算表 |
| 團體獎 (懶骨頭、沙發) | 只有青少有 |

### 三、獎品和兌換：一份 Google 試算表

| 分頁 | 欄位 |
|---|---|
| 青少獎品、主堂獎品 | 獎品、分數、上架 |
| 青少兌換、主堂兌換 | 日期、名字 (下拉選單)、獎品、分數、照片連結 (可不填) |

- 可以換的分數 ＝ 讀經得分 − 兌換分頁裡這個人每一列的分數加總。填錯就直接改或刪那一列，沒有隱藏的撤銷規則。
- 試算表一改，Apps Script 就把內容送到後端；後端不輪詢。
- 試算表放在青少處的雲端資料夾，維護者自己分享給主堂同工。
- App 裡的獎品管理和現場兌換畫面拿掉。

### 四、管理頁 (指紋解鎖)

列出所有後台規則 (分數怎麼算、人數怎麼算、週刊怎麼認、青少／主堂歸屬、誰是管理者) 和所有後台文件的連結 (獎品試算表、讀經表、中亮排班表、報名表單)。連結從私人部署設定讀，不進程式碼。

### 五、拿掉

提名投票、AI 估價 (含後端每 20 秒的背景工作)、團體獎最後一行「下一個獎品，由你決定」、App 裡的獎品管理和現場兌換。不放替代連結；需要投票時線下進行。

### 六、驗收

這一版做完，連同 0.5.32 一起在手機上驗一次。
