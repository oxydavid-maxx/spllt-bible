# 0.5.22 發布與驗收計畫

> **Execution:** The current native owner implements the complete release candidate, owns every FOCUS loop, and produces the exact candidate for RC. Steps use checkbox syntax for tracking.

**Goal:** 發布 0.5.22/45，完成同一個正式 APK 的下載、系統安裝及使用者結果驗收，保留前一輪失敗紀錄。

**Architecture:** 沿用已合併的功能與共用面板，不推測性修改朗讀程式。先補足 iOS 失敗現場的原生截圖與播放器診斷，正式候選若再失敗就依證據定位、修正；不重跑失敗斷言來取得綠燈。

**Tech Stack:** Expo SDK 56、React Native 0.85、Vitest、Maestro 2.10.0、Android 系統安裝流程。

## Global Constraints

- 本次功能範圍為 PR #34 的六項改動、清單下拉關閉、讀經/朗讀/日記保存/完成後積分的主要流程，以及正式發布入口。
- 版本只改 app.json 的 version 與 android.versionCode；iOS buildNumber 繼續自動衍生。
- 不新增 secret、不付款、不開通 Apple 帳號；iOS 本輪維持 Release 模擬器驗證。
- 不清手機資料、不解除安裝、不改設定、不鎖屏、不用正式帳號寫入測試資料。
- 發布 APK 與正式 HTML 入口下載/安裝的 APK 必須同一份 bytes；不以 adb install 代替正式流程。
- 原有的 unit、android、ios CI、原生/資源守門與功能斷言全部保留。
- 不把「HTTP 成功」「診斷已補齊」「後一輪通過」說成未知歷史原因已根除。
- 不為發布再跑本機全套；執行受影響測試、typecheck，並核對完整驗收表與 exact input bindings。
