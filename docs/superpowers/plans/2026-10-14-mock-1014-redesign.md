# 積分頁、讀經頁靈修、公告改版 實作計畫 (2026-10-14)

> **Execution:** 一個負責人在 `feat/mock-1014-redesign` 做完整個候選版本，每個任務自己跑 FOCUS (先紅再綠)，最後對組好的候選跑一次 RC。

**Goal:** App 照維護者 2026-10-14 核准的 mock (第 10 版) 改版：積分頁分「團體 / 個人」、讀經頁加「靈修」分頁和兩個圈圈、公告每個主日一張卡。

**Architecture:** 後端加三組唯讀/自己的資料 API (靈修內容、靈修完成、團體讀經統計與積分歷史)，全部是新增，舊版 App 不受影響。App 端新元件放 `src/ui/gamification/`、`src/ui/devotion/`，原有的完成打卡、朗讀、公告資料格式不改。

**Tech Stack:** Expo SDK 56 / RN 0.85、node:sqlite 後端、vitest、react-native-web (只用來在瀏覽器對照 mock)、expo-speech (新，朗讀靈修)。

## Global Constraints

- 靈修**不算分**，也不算進團體和個人的讀經統計；畫面上不寫「不算分」。
- 團體人數「滿 2 人才顯示」；團體獎只算讀經 (當月讀經 15 天算一份)。
- 靈修內容只從後端給登入的人，不放進公開 repo；原文檔放後端主機的私人資料夾 (`QINGMU_DEVOTIONAL_DIR`)。
- 一份程式碼兩個平台；平台差異只用 `Platform.OS` 並寫原因。
- 後端只新增路由和資料表，舊版 App 照常可用。
- 不新增常駐程式；閒置時不發網路請求。
- 公開 repo 不放成員名字。

## 決定 (維護者 2026-10-14，對話中定案，同一個 PR 寫進 `docs/features/`)

| 範圍 | 決定 |
|---|---|
| 積分頁 | 上「團體」下「個人」；分頁只剩「自己 / 好友 / ⋯」；「全體 (管理)」收進頭像「我的帳戶」最下面，淡色，只有管理員看得到 |
| 團體 | 「青少一起讀經」：今天 / 昨天幾人讀、每天人數日曆 (滿 2 人才顯示)、本月人次與最多的一天；團體獎：新的懶骨頭 (15 人讀滿一個月，累積 2 個月)、新沙發 (20 人，累積 4 個月)、[下一個獎品，由你決定] |
| 個人 | 讀經日曆下兩顆按鈕：左金「完成今日靈修」、右綠「完成今日讀經」；讀了靈修的日子日期下有金色小字「靈修」；圖表一張，「總積分 / 每月」切換，靈修用金色虛線，每月柱上的虛線中間寫數字 (一般字重) |
| 一起走過 | 被「團體」取代，積分頁不再顯示 (後端 API 保留給舊版) |
| 日記 | 分頁列拿掉「日記」；日記資料仍留在手機，不刪除 |
| 讀經頁 | 「靈修」分頁每天都在；右下角 金圈 (靈修) · 綠圈 (完成讀經) · ▶；該按的那顆展開成有字的長鈕；第一次按金色「跟傳道一起讀 ›」就跳到靈修並打開「⋯」裡的「跟傳道一起讀」 (預設開) |
| 播放順序 | 經文 → 靈修 (系統 AI 聲音朗讀，讀到哪段亮哪段) → 詩歌 (YouTube，螢幕亮著才播) |
| 公告 | 下次聚會深綠日期方塊；「上次講道」和「以前的主日」合成「講道紀錄」，每個主日一張卡、左邊日期欄、最新一週標「上週」；連結改成文字按鈕加小圖示；沒資料的第二堂縮成一行；同角色兩個檔案寫「報告投影片 1、2」 |
