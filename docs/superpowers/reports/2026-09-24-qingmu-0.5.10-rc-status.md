# 青牧 0.5.10/code31 RC — change list and acceptance status

Date: 2026-09-24. PR #3 remains draft. This report describes the source candidate; it is not release approval.

## Change list

- Reader and Diary share one audio player/queue. Diary can remain open during playback and a real chapter EOF advances through the assigned queue; returning to Reader keeps the live/EOF-advanced chapter.
- Explicit Today entry from Points or Announcements resets free-browse position to the first assigned chapter (TIT.1) without starting playback. Returning from Diary preserves the active chapter instead.
- Reader header shows Taipei weekday/date and the complete assigned reference range. The selected chapter remains in its own lower capsule; More stays on the right.
- The Reader completion control and Points completion button use the shared daily completion state. The server returns `pointsDelta` from the existing idempotent completion transaction, and the client shows one once-only award feedback for an actual positive delta.
- The latest source also removes the zero-width child that collapsed the completion/play spacing and aligns the bottom controls by 4dp. This latest spacing fix is source-tested but has not yet been built or checked on a phone.
