# 閱讀頁：需求、決策與待決定事項

> 討論或修改閱讀頁前先讀這份。已定案的項目不要再重談；新決定直接改這份，並附上日期與來源。
> 最後更新：2026-09-25

## 1. 大前提

- **目標**：讓每位學生一口氣讀完、聽完「今天」的指定進度（例：多1 → 詩99 → 詩100）。這和 YouVersion 自由閱讀器的目標不同。（2026-09-25）
- **做法**：以上述目標為前提，優先套用 YouVersion 與大廠已驗證的 UI/UX，不自己發明，也不被 owner 原本的 UI 想像綁住。（2026-09-25）
- **給學生用**：compact、一致、簡單；不要 over-do；不改壞原有功能。（2026-09-22）

## 3. YouVersion 實機觀察（Android 11.32.1，2026-09-25）

| 情況 | YouVersion 的做法 |

| 一般狀態 | 狀態列、系統導覽列、tab 都在；書名寫在內文（大字書名＋首字章號）；底部浮動 ▶ 與「‹ 提多書 1 ›」 |
| 往下捲 | 狀態列、上方圖示、tab、系統導覽列全部收起，只留底部細條（▶＋章名） |
| 往上小滑（約 300px） | 不出來，避免誤觸 |
| 往上大滑（約 1000px）、回到章首、捲到章尾 | 工具列出來 |
| 沉浸中按返回鍵 | 先叫回工具列，位置不變，不離開頁面 |
| 點經文 | 選取經節（畫重點、筆記、複製、分享），不是切換工具列 |
| 點底部細條的章名 | 開書卷/章節選單 |

## 4. 青牧目前的沉浸問題（0.5.10 實機，2026-09-24）

- 症狀：章首往下拉、點頂端空白、點播放鈕兩側都叫不回工具列，只有點經文可以，但畫面沒有提示；沉浸中按返回鍵直接跳到公告頁。
- 根因：恢復工具列靠「內容往上捲」，章首捲不動就沒有訊號；空白帶沒有接點擊；點一下經文就切換沉浸；切換時閱讀區會重排，捲動觸發的切換偶爾跳回章首；沒有沉浸專用的返回鍵處理；只有讀經頁藏系統導覽列，tab 列在各頁高度不同。
- 修法方向：照第 3 節的 YouVersion 規則；另外加一個保險：點底部細條也能叫回。
