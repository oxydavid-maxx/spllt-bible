### SDK 靜態核對範圍

本輪另讀指定依賴中 `@youversion/platform-react-native-expo-ui` 1.5.0、`@youversion/platform-react-native-expo-core` 1.5.0 與 `@youversion/platform-react-ui` 2.12.0 的已安裝原始碼；檔案 SHA-256 記在交付證據，這不是實機或正式安裝驗收。

- `YouVersionReader.tsx` 的 Provider 不傳 `auth`；core 的 `build/youversion-provider.js` 只有傳 auth 才包 `AuthProvider`。
- UI 的 `build/native/bible-reader.js` 在 auth unconfigured 時給空 swatches；`build/native/bible-verse-action-sheet.js` 仍渲染出處、Copy、Share。沒有自訂 `onShare` 時走 React Native `Share.share`。因此本表補列分享鈕，不把「沒有 onShare」解讀成沒有分享。
- 設定 DOM 委派給 web UI 的 `BibleThemeSettingsContent`：字級減/加、行距切換、兩個字型選項。選章 DOM 委派 `BibleChapterPicker.Content`，含搜尋/書卷/章節內容；外層共用完成返回。
- 未打開任何官方登入/同意頁，也未變更 `docs/features/reader.md` 原有的待確認說法；本檔補上這次靜態觀察與其適用依賴，將產品原因留給維護者。
